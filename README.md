## 🧠 About Me

<img align="right" width="380" src="https://raw.githubusercontent.com/ohcnetwork/coronasafe-charts/master/.github/assets/data-analysis.gif" />

I'm an **AI/ML Engineer** specializing in **clinical NLP, ensemble methods, and sports analytics**, currently completing my **MSc in Artificial Intelligence & Data Science** at the **University of Macedonia**.

My work centers on building production-grade ML systems — from multi-label clinical text classification on Greek medical records to full-stack data transparency pipelines. I care deeply about **rigorous evaluation**, **ensemble/meta-optimization strategies**, and **shipping things that actually run in production**, not just in notebooks.

- 🔬 **Research Focus:** Clinical NLP, entity linking, ensemble learning, model calibration

<details>
<summary><b>🏥 BioASQ ElCardioCC 2026 — Clinical NLP Ensemble</b> ✅ Completed</summary>
<br/>

1st-place multi-label ICD-10 classifier for Greek cardiology discharge summaries (115 codes, 2,500 documents). A 6-component ensemble combining Greek BERT, two XLM-RoBERTa variants, dictionary rules, retrieval, and NER+EL modules, optimized via custom metaheuristic search.

| | |
|---|---|
| **Stack** | Python, Hugging Face Transformers, CatBoost, pandas, Weights & Biases |
| **Scale** | 115 ICD-10 codes, 2,500 clinical documents |
| **Performance** | 0.8667 micro-F1 (test), +1.8pp over best standalone model |
| **Security** | N/A (research pipeline) |
| **Impact** | 1st place, published at CLEF 2026 (Sept 21–24, Jena, Germany), 8 co-authors |
| **Repository** | 🔒 Private |

Led the design of a multi-component ensemble architecture for extreme multi-label classification under class imbalance, fine-tuning transformer models on domain-specific Greek medical text and optimizing ensemble weights via random search, hill-climbing, and variable neighborhood search.
